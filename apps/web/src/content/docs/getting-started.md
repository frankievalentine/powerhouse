## Bootstrap flow

1. Run `install.sh`.
2. Install Homebrew and Bun if missing.
3. Resolve the selected profile and domain from local manifests.
4. Install missing tools with the appropriate backend.
5. Install curated skills globally for the selected agent targets.

## V1 boundaries

- macOS and Linux only
- CLI-first, no GUI installation path
- plugins, MCP installers, and config symlink management are deferred
