Web content fetching and HTML-to-markdown conversion for Claude Code.

## Details

| | |
|---|---|
| **Server name** | `fetch` |
| **Target agents** | `claude-code` |
| **Server kind** | stdio |
| **Source** | `@modelcontextprotocol/server-fetch` |
| **Supported scopes** | global, project, local |
| **Supported platforms** | macOS, Linux, WSL |

## Installing

Install standalone:

```bash
powerhouse mcp install claude-fetch
```

Or it will be installed automatically during setup if it is included in your active harness selection.
