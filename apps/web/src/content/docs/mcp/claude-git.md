Git repository operations for Claude Code via the official MCP git server.

## Details

| | |
|---|---|
| **Server name** | `git` |
| **Target agents** | `claude-code` |
| **Server kind** | stdio |
| **Source** | `mcp-server-git` |
| **Supported scopes** | project, local |
| **Supported platforms** | macOS, Linux, WSL |

## Installing

Install standalone:

```bash
powerhouse mcp install claude-git
```

Or it will be installed automatically during setup if it is included in your active harness selection.
