Install the Context7 MCP server for Cursor.

## Details

| | |
|---|---|
| **Server name** | `context7` |
| **Target agents** | `cursor` |
| **Server kind** | stdio |
| **Source** | `@upstash/context7-mcp` |
| **Supported scopes** | global, project |
| **Supported platforms** | macOS, Linux, WSL |

## Installing

Install standalone:

```bash
powerhouse mcp install cursor-context7
```

Or it will be installed automatically during setup if it is included in your active harness selection.
