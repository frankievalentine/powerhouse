Google Workspace access for Gemini CLI.

## Details

| | |
|---|---|
| **Target agent** | `gemini-cli` |
| **Install kind** | native-cli |
| **Supported scopes** | global |
| **Supported platforms** | macOS, Linux, Windows, WSL |
| **Source** | `https://github.com/gemini-cli-extensions/workspace` |


## Installing

Install standalone:

```bash
powerhouse integration install gemini-workspace
```

Or it will be installed automatically during setup if it is included in your active harness selection.
