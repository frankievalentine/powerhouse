Official GitHub plugin for Claude Code.

## Details

| | |
|---|---|
| **Target agent** | `claude-code` |
| **Install kind** | native-cli |
| **Supported scopes** | global, project, local |
| **Supported platforms** | macOS, Linux, WSL |
| **Source** | `github@claude-plugins-official` |


## Installing

Install standalone:

```bash
powerhouse integration install claude-github
```

Or it will be installed automatically during setup if it is included in your active harness selection.
